# 会话收尾协议

本 skill 是 AGENTS.md「项目记忆协议」在 Claude Code 上的快捷触发器。
事实源是 AGENTS.md;本文件只负责把那段协议变成一个 /wrap 动作。

## 执行步骤

1. 回顾本次会话,区分出三类信息:
   - **进度**:完成了什么、当前状态、下一步、新增的遗留事项。
   - **决策**:做了哪些会影响后续工作的技术 / 产品选择。
   - **踩坑**:哪些方案试过但失败了。

2. 更新 `.ai/PROGRESS.md`:
   - 刷新「当前状态」「下一步」「遗留 / 待澄清」。
   - 「进度日志」最上方加一行(日期 + 一句话)。
   - 勾选「任务清单」中**已端到端验证**的项;未验证的不勾。
   - 更新顶部「最后更新」日期。

3. 仅当本次确有决策时,追加到 `.ai/DECISIONS.md`(只增不改),按其模板:
   背景、选了什么、放弃的备选、风险。

4. 仅当本次确有失败方案时,追加到 `.ai/GOTCHAS.md`(只增不改),按其模板:
   试过什么、结果、原因、现在的做法。

## 注意

- 没有决策就不要硬写 DECISIONS;没踩坑就不要硬写 GOTCHAS。宁缺毋滥。
- 提炼要具体可执行,不写"继续推进"这类空话。
- 更新完简短汇报改了哪几个文件,不复述全文。
